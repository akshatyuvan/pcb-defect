  feature map (4, 4) | max |grad_weight - W/(H*W)| = 0.000e+00 | pass=True
  PCBNet is GAP -> single Linear, so d logit_c / d fmap[k,i,j] is the
  constant W[c,k]/(H*W). Grad-CAM therefore reduces exactly to CAM.
  A pass here proves the hook, the gradient path and the class indexing
  are all correct, which is otherwise a silent failure mode.

  The final feature map is 4x4 for a 64x64 input, so the 'final' CAM is a
  16x upsample and localises to roughly a 16x16 region. Any apparent
  pixel precision in the heatmaps is bilinear interpolation, not evidence.
  This belongs in the README stated plainly, not implied away.
